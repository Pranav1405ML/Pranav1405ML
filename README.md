### 🔍 Cortex — AI Search Engine &nbsp; [![Repo](https://img.shields.io/badge/→_Code-0a192f?style=flat-square&logo=github&logoColor=00e5ff)](https://github.com/Pranav1405ML/Cortex)

**A Perplexity-inspired search engine — not a chatbot wrapper, an actual retrieval pipeline.**

Built an end-to-end AI search system that takes a user query, retrieves real web sources, embeds and chunks content into vector storage, performs similarity search, and synthesizes answers with source attribution via LLM.

```
Query → Web Retrieval → Embedding → pgvector Search → LLM Synthesis → Cited Answer
```

### 🤖 Coding Agent &nbsp; [![Repo](https://img.shields.io/badge/→_Code-0a192f?style=flat-square&logo=github&logoColor=00e5ff)](https://github.com/Pranav1405ML/Coding-Agent)

**A CLI agent that turns an LLM into an iterative, tool-using engineer with persistent memory.**

Designed a multi-step autonomous coding agent — it reasons about tasks, selects tools, reads/writes files, executes code inside isolated Docker containers, observes results, and iterates. State persists across sessions via SQLite.

```
Prompt → Agent Reasoning → Tool Call → Docker Execution → Observation → Loop
```

### 🔧 CPU Simulator &nbsp; [![Repo](https://img.shields.io/badge/→_Code-0a192f?style=flat-square&logo=github&logoColor=00e5ff)](https://github.com/Pranav1405ML/CPU_SIMULATOR)

**A cycle-accurate CPU simulator — computing understood from first principles.**

Built a custom microarchitecture simulator from scratch: instruction set design, data paths, control signal generation, and cycle-accurate execution. Not a toy — a tool for understanding the hardware-software boundary.

```
Instruction Fetch → Decode → Execute → Memory → Write Back (cycle-accurate)
```
